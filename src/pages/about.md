Whelp, welcome to my blog.

I'm a Berlin-based freelance software developer with over 15 years of experience. Mostly TypeScript and JavaScript, with occasional Python, C++, Dart, and Swift. These days that mainly means React Native, plus React on the web, Flutter, and various backends.

I feel like we've entered some kind of software development renaissance (or apocalypse) with the advent of agentic coding. I'm constantly trying out new things and figured I might as well write some of it up.

I'll try to keep it mostly hands-on. I'm not into the doom / hype cycling or the endless opinionating and far future predictions, so this is going to be about things that work right now.

## Projects

- **[Juggler](https://github.com/nielsmadan/juggler)** — A native macOS app that tracks your running coding agent sessions and takes you to the next one that needs attention with a global hotkey. No new terminal, no forced worktrees, no workflow changes.
- **[splashdown](https://github.com/nielsmadan/splashdown)** — Per-checkout simulators, emulators, and dev ports, so two worktrees of the same project never clash. A git hook allocates free resources on every branch switch, coordinated through a machine-wide registry.
- **[agentic-coding](https://github.com/nielsmadan/agentic-coding)** — My version-controlled config for Claude Code, Codex, Antigravity, OpenCode, and Pi: skills, hooks, permissions, and project templates in one repo, installed by symlink.
